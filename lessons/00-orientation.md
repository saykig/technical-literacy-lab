## The question

When someone says “run this code,” what actually happens?

For our first lesson, use this simple description: you write instructions in an editor, an interpreter executes them, and you inspect the output. A browser-based learning site can provide the editor and execution environment without your installing Python locally. See [Futurecoder and Python Tutor](../SOURCES.md).

Read this without worrying about memorizing terminology:

```python
papers_read = 3
print(papers_read)
```

The first line associates the name `papers_read` with the number 3. The second asks Python to display the value associated with that name. The displayed `3` is output; it is not another line of source code.

A `.py` file is a saved text file containing Python code. An editor lets you change it. Python executes it. A terminal is one possible place to issue the command that starts execution. These are different roles, even when one application presents them together.

## First task

Open Futurecoder from the link in README.md. Find where source code is entered and where output appears. Try the two lines above using its “Just code” option, or use Python Tutor.

Explain: which part did you write, which part did Python produce, and what would you change to display 4 instead?

Do not install a new application merely to finish this task. Do not paste private documents into a browser coding site.

## Readiness check
